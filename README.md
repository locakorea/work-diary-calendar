# work-diary-calendar
Calendar-linked AI work diary system

## 개발 로드맵

### 1단계: 내부 달력형 업무다이어리
- 월/주/일 뷰 전환이 가능한 사내용 캘린더 UI 제공
- 날짜별 업무 기록(제목, 설명, 태그, 상태) 기본 입력
- 사용자별/팀별 보기 필터

### 2단계: 업무 저장/수정/삭제
- 업무 CRUD(생성/조회/수정/삭제) API 및 화면 연결
- 업무 상태(예정/진행중/완료/보류) 관리
- 수정 이력(누가/언제/무엇을) 최소 로그 저장

### 3단계: 오늘 업무 요약
- 당일 등록/완료/미완료 업무 자동 집계
- 개인 기준 “오늘 할 일” 우선순위 뷰 제공
- 마감 임박 업무 하이라이트

### 4단계: 주간/월간 리포트
- 주간/월간 완료율, 지연률, 업무 분포 리포트 생성
- 프로젝트/태그/담당자별 통계 필터
- PDF/링크 형태의 공유용 요약 리포트 제공

### 5단계: Google Calendar 연동
- Google OAuth 인증 및 캘린더 권한 연결
- 양방향 동기화(앱 ↔ Google Calendar)
- 동기화 충돌 시 우선순위 규칙 및 수동 병합 UI 제공

### 6단계: 알림/반복업무/AI 회고 기능
- 마감/시작/리마인더 알림(이메일/푸시/메신저)
- 반복 업무 템플릿(매일/매주/매월/커스텀)
- AI 기반 회고: 주간 성과 요약, 병목 분석, 다음 주 액션 추천

## MVP 권장 범위
- 1~3단계를 우선 구현하여 실제 사용 가능한 내부 버전 완성
- 4단계는 핵심 지표만 먼저 제공 후 확장
- 5~6단계는 외부 연동/자동화 단계로 분리 출시
